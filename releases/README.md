# Development Builds

Pokémon Wildbound development builds are kept here by version.

The repository does **not** contain commercial Pokémon Platinum ROM images. Each version instead provides the project assets, builder/patch information, checksums, testing notes, and known limitations required to reproduce or test that build using a clean supported base ROM.

## Versions

- [`InDev 0.0.1 — Intro Test`](InDev-0.0.1/) — title screen / Professor intro technical test.

Future development builds will continue the `InDev` numbering scheme until the project reaches larger alpha/beta milestones.
