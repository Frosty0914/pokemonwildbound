# Changelog

## InDev 0.0.1 — Intro Test

Initial development version.

### Added
- First Pokémon Wildbound title-screen asset replacements.
- Celebi-themed title presentation work.
- Professor Linden intro graphics.
- New male protagonist intro graphics.
- Intro/new-game modification groundwork.
- DS-native graphics conversion and rebuild tooling.
- Initial Veyra design data and 180-species regional Pokédex data.

### Known limitations
- This is an intro technical test, not a full playable Veyra build.
- Willowmere and all new overworld maps are not implemented.
- Platinum's underlying gender-selector structure is not fully removed in this build.
- Celebi is currently represented through 2D title graphics rather than a complete replacement of Platinum's original Giratina 3D title system.

See `releases/InDev-0.0.1/` for detailed test notes.
